# Прогнозирование свойств композиционных материалов

Дипломный проект

Репозиторий описывает процесс изучения, анализа, предобработки данных исходного датасета.

На основе полученных результатов были построены модели прогнозирования, написана и обучена нейросеть, разработан графический интерфейс.

Кейс основан на реальных производственных задачах Центра НТИ «Цифровое материаловедение: новые материалы и вещества» (структурное подразделение МГТУ им. Н.Э. Баумана).

## Запуск приложения

cd app
streamlit run app.py

## Модели

- Ridge-регрессия — прогноз модуля упругости и прочности
- Нейронная сеть — прогноз соотношения матрица-наполнитель
